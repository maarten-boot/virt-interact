## 2. Code checked against the Spec and Plan

| # | Finding | Severity | Proposed fix |
|---|---------|----------|--------------|
| C1 | **A command timeout on one domain aborts the whole host.** In `libvirt.rs`, every `run(..).await?` returns SSH errors, so `SshError::Timeout` stops the refresh. This includes `domblkinfo`, which can hang realistically, for example on an unreachable NFS or iSCSI disk. SPEC-013 says "a failing `domblkinfo` only makes that disk's size unknown". SPEC-012 says the session stays usable after a command timeout. | Medium | Treat a timeout on `domblkinfo` as size unknown, with a warning. Record a timeout on `dominfo` or `dumpxml` on that domain and continue. Connection-level SSH errors stay fatal. Add a test with `MockRunner::with_delay` and a short command timeout. This needs a timeout in the backend or the runner, because `MockRunner` has none. Proposal: an optional `command_timeout` on `LibvirtBackend`, applied with `tokio::time::timeout` around each command, in addition to the session's own timeout. |
| C2 | `exit 126` ("bash: /usr/bin/virsh: Permission denied", when virsh is not executable) is classified as libvirt *PermissionDenied*, with the hint about the `libvirt` group. That hint is misleading in this case. | Low | Map exit status 126 to `CommandFailed` with the detail, or to `VirshNotFound` with a "not executable" wording. Add a test case. |
| C3 | `sudo -n virsh` where virsh is missing gives "sudo: virsh: command not found". The code correctly classifies it as *VirshNotFound* (the not-found check runs before the sudo check), but no test covers it. | Low (test gap) | Add it to `classify_stderr`. |
| C4 | Listen `type="network"`: the live XML also carries the resolved `address`, which the code drops (`Listen::Network(name)` only). SPEC-018 (v1.1) needs that address to open a tunnel. | Low (v1.1) | Change the variant to `Network { network, address }` now, while the model has no other users yet. |
| C5 | `for_host()` and `HypervisorBackend::name()` are not covered by any test. | Low | Add a test that a default `HostConfig` gives the libvirt backend, and that an invalid prefix gives `Config`. |
| C6 | The model has `Serialize`/`Deserialize` for the cache (SPEC-014), but no round-trip test. | Low | Add a serde round-trip test when the cache is built (Plan 4.4). No action now. |

No mismatches were found for SPEC-009 (state, persistent/transient, autostart), SPEC-010 (every listed section is filled), SPEC-011 (closed enum; prefix checked at config load and in the builder) or SPEC-017 (trait plus `CommandRunner`).
