## 6. Other improvements suggested

1. **Push the repo / run CI.** This is now the biggest open risk (C5). The Windows paths have never been compiled.
2. **Refactor authentication state:** move `user`, `rsa_hash`, `tried`, `tried_keys` into an `AuthState` struct. That removes the 8-argument function and makes C1 easier to fix cleanly.
3. **`MaxAuthTries` and big agents:** an agent with many keys can use up the server's attempts (default 6) before a configured key file is tried. Suggestion: when `identity_explicit`, first offer the agent keys that match a configured key file (via its `.pub`), then the rest. This is close to OpenSSH's `IdentitiesOnly` behaviour.
4. **System-wide known_hosts:** OpenSSH also checks `/etc/ssh/ssh_known_hosts` (read-only). A host known only there is currently treated as unknown, and the user is asked. Suggest SPEC-008 + implementation: read the global file too, but write only to the user's file.
5. **Real-host check (Plan 2.7):** `cargo run -p vi-ssh --example ssh-run -- <host> virsh version` against your libvirt host, with and without the agent.
